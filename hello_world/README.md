# C - Hello, World

This project is an introduction to the C programming language and its compilation process. It covers the 4 stages of compilation (Preprocessing, Compilation, Assembly, Linking), standard output functions (`puts` and `printf`), and basic data types.

## Tasks

| File | Description |
| --- | --- |
| `0-preprocessor` | Bash script that runs a C file through the preprocessor and saves the result into another file named `c`. |
| `1-compiler` | Bash script that compiles a C file without linking, producing an object (`.o`) file. |
| `2-assembler` | Bash script that generates the assembly code (`.s` file) from a C file. |
| `3-name` | Bash script that compiles a C file and creates an executable named `cisfun`. |
| `4-puts.c` | C program that prints `"Programming is like building a multilingual puzzle` followed by a new line using `puts`. |
| `5-printf.c` | C program that prints `with proper grammar, but the outcome is a piece of art,` followed by a new line using `printf`. |
| `6-size.c` | C program that prints the size of various data types (`char`, `int`, `long int`, `long long int`, `float`) on the machine. |
