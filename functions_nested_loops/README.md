# C - Functions, nested loops

This project covers the concepts of functions, nested loops, variable scope, and prototypes in C. It includes exercises on printing characters and strings, character classification, sign and absolute value computations, and iterative loops.

## Tasks

| File | Description |
| --- | --- |
| `0-putchar.c` | C program that prints `_putchar`, followed by a new line. |
| `1-alphabet.c` | C program that prints the alphabet in lowercase, followed by a new line. |
| `2-print_alphabet_x10.c` | C function that prints 10 times the alphabet in lowercase, followed by a new line. |
| `3-islower.c` | C function that checks for a lowercase character (`1` if lowercase, `0` otherwise). |
| `4-isalpha.c` | C function that checks for an alphabetic character (`1` if letter, `0` otherwise). |
| `5-sign.c` | C function that prints the sign of a number (`+`, `0`, or `-`) and returns `1`, `0`, or `-1` respectively. |
| `6-abs.c` | C function that computes the absolute value of an integer. |
| `7-print_last_digit.c` | C function that prints and returns the last digit of a number. |
| `8-24_hours.c` | C function that prints every minute of the day of Jack Bauer, starting from `00:00` to `23:59`. |
| `9-times_table.c` | C function that prints the 9 times table, starting from 0. |
| `10-add.c` | C function that adds two integers and returns the result. |
| `11-print_to_98.c` | C function that prints all numbers from `n` to `98`, separated by a comma and space. |
