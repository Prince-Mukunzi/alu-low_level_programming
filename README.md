# ALU Low Level Programming

This repository contains low-level programming projects written in C as part of the curriculum.

## Projects

* [hello_world](./hello_world): Introduction to C, GCC compilation phases, standard output functions, and basic data types.
* [variables_if_else_while](./variables_if_else_while): Conditionals, comparison operators, and loops in C.
* [functions_nested_loops](./functions_nested_loops): Functions, nested loops, variable scope, and header prototypes in C.
